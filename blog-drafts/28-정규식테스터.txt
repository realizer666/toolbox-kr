━━━━━━━━━━━━━━━━━━━━━━━━━━━━

이메일 형식 검증, 전화번호 추출, 특정 패턴 찾기... 정규식은 강력하지만 작성하기 까다롭습니다.
작성한 정규식이 제대로 동작하는지 코드에 넣기 전에 미리 테스트해보고 싶은데,
매번 콘솔에서 확인하기 번거로우셨죠?

오늘은 회원가입 없이 바로 사용할 수 있는
무료 정규식 테스터 사이트를 소개해드릴게요.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 모두의도구 - 정규식 테스터

▶ https://toolbox-kr.vercel.app/tools/developer/regex-tester

[여기에 도구 스크린샷 첨부]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 이 도구의 장점

1. 회원가입 없이 바로 사용
2. 실시간으로 매칭 결과를 하이라이트 표시
3. 매칭 그룹과 캡처 그룹 결과 상세 확인
4. 다양한 정규식 플래그(g, i, m 등) 지원
5. 모바일에서도 사용 가능

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 이런 분들에게 추천

- 정규식을 작성하고 바로 테스트해보고 싶은 개발자
- 데이터에서 특정 패턴을 추출해야 하는 데이터 분석가
- 정규표현식을 공부하고 있는 프로그래밍 입문자
- 텍스트 검색/치환 패턴을 만들어야 하는 시스템 관리자

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 사용 방법

1. 사이트에 접속합니다
2. 정규식 패턴을 입력합니다
3. 테스트할 문자열을 입력합니다
4. 실시간으로 매칭 결과와 그룹을 확인합니다

[여기에 사용 화면 스크린샷 첨부]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 다른 유용한 도구도 있어요

- URL 인코더 - URL 특수문자 인코딩/디코딩
- Base64 변환 - 텍스트 인코딩 변환
- JSON 포맷터 - JSON 데이터 정리
