■ 이 계산기의 특징

1. 원리금 균등상환 / 원금 균등상환 모두 지원
2. 월 납입금 바로 확인
3. 총 이자, 총 상환 금액 한눈에
4. 회원가입 없이 무료 사용
5. 모바일에서도 사용 가능

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 원리금 균등 vs 원금 균등, 뭐가 다를까?

원리금 균등상환: 매달 같은 금액을 납부
→ 매달 부담이 일정해서 계획 세우기 편함

원금 균등상환: 매달 원금은 같고 이자가 줄어듦
→ 총 이자가 더 적지만 초반 부담이 큼

두 방식 모두 계산해보고 비교해보세요!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 사용 방법

1. 대출 금액을 만원 단위로 입력 (예: 30000 = 3억)
2. 연 이자율 입력 (예: 3.5)
3. 대출 기간 입력 (예: 30년)
4. 상환 방식 선택
5. 바로 결과 확인!

[여기에 사용 화면 스크린샷 첨부]
