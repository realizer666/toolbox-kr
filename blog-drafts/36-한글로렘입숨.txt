웹 디자인이나 앱 UI를 만들 때 텍스트 영역을 채워야 하는데,
영어 Lorem Ipsum은 한글과 글자 크기가 달라서 실제 느낌이 안 나죠.
한글로 된 자연스러운 더미 텍스트가 필요할 때 유용한 도구입니다.

무료 한글 로렘입숨 사이트를 소개해드릴게요.

■ 이 도구의 장점

1. 회원가입 없이 바로 사용
2. 자연스러운 한국어 더미 텍스트 생성
3. 문단 수, 문장 수 등 분량 조절 가능
4. 생성된 텍스트 원클릭 복사 기능
5. 모바일에서도 사용 가능

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 이런 분들에게 추천

- 한국어 웹사이트의 UI 시안을 제작하는 디자이너
- 프론트엔드 레이아웃 테스트에 한글 텍스트가 필요한 개발자
- 인쇄물이나 브로슈어 시안에 임시 텍스트를 넣어야 하는 편집 디자이너
- PPT 템플릿에 예시 텍스트를 채워야 하는 기획자

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 사용 방법

1. 사이트에 접속합니다
2. 필요한 문단 수나 글자 수를 설정합니다
3. 생성 버튼을 클릭합니다
4. 생성된 한글 더미 텍스트를 복사해서 사용합니다

[여기에 사용 화면 스크린샷 첨부]
