엑셀에서 내보낸 CSV 파일을 API에 맞는 JSON 형식으로 바꿔야 하거나,
JSON 데이터를 엑셀에서 열 수 있는 CSV로 변환해야 할 때가 있습니다.
파이썬 스크립트를 짜기엔 너무 간단한 작업인데, 수동으로 하기엔 귀찮죠.

무료 CSV ↔ JSON 변환 사이트를 소개해드릴게요.

■ 이 도구의 장점

1. 회원가입 없이 바로 사용
2. CSV → JSON, JSON → CSV 양방향 변환 지원
3. 한글 데이터도 깨짐 없이 정확하게 변환
4. 변환 결과 원클릭 복사 및 다운로드 가능
5. 모바일에서도 사용 가능

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 이런 분들에게 추천

- 엑셀 데이터를 JSON API 형식으로 변환해야 하는 개발자
- JSON 응답 데이터를 엑셀에서 분석하고 싶은 데이터 분석가
- 대량의 데이터 형식을 빠르게 변환해야 하는 기획자
- 데이터 마이그레이션 작업 중인 시스템 관리자

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 사용 방법

1. 사이트에 접속합니다
2. CSV → JSON 또는 JSON → CSV 변환 방향을 선택합니다
3. 변환할 데이터를 붙여넣기 합니다
4. 변환 결과를 확인하고 복사하거나 다운로드합니다

[여기에 사용 화면 스크린샷 첨부]
