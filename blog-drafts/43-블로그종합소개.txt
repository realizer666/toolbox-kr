■ 이 사이트의 장점

1. 회원가입 없이 바로 사용
2. 43개 도구를 한 곳에서 모두 이용 가능
3. 깔끔한 UI와 한국어 인터페이스
4. 모든 도구가 100% 무료
5. 모바일에서도 사용 가능

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 카테고리별 도구 소개

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

◆ 텍스트 도구

글자수 세기, 텍스트 변환 등 텍스트 관련 작업을 도와주는 도구들입니다.

- 글자수 세기 - 공백 포함/제외 실시간 글자수 카운트
- 텍스트 변환기 - 대소문자 변환, 줄바꿈 제거 등
- 텍스트 비교 - 두 텍스트의 차이점 비교
- 메모장 - 온라인 메모장, 자동 저장
- 한영 타이핑 변환 - 잘못 친 한영 타이핑 변환
- 맞춤법 검사기 - 한국어 맞춤법/띄어쓰기 검사
- 단어 빈도 분석기 - 텍스트 속 단어 출현 빈도 분석
- 텍스트 암호화 - 텍스트 인코딩/디코딩

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

◆ 변환 도구

단위, 진법, 파일 형식 등 다양한 변환 작업을 처리합니다.

- 단위 변환기 - 길이, 무게, 온도 등 단위 변환
- 진법 변환기 - 2진법, 8진법, 10진법, 16진법 변환
- 환율 계산기 - 실시간 환율 기반 통화 변환
- 이미지 변환기 - 이미지 형식(JPG, PNG, WebP) 변환
- 이미지 리사이즈 - 이미지 크기 조절

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

◆ 계산 도구

숫자 관련 계산과 데이터 정리에 필요한 도구들입니다.

- 퍼센트 계산기 - 할인율, 비율 등 퍼센트 계산
- 나이 계산기 - 만 나이, 한국 나이 계산
- 날짜 계산기 - 두 날짜 사이 간격 계산
- BMI 계산기 - 체질량지수 계산
- 학점 계산기 - 대학교 학점/GPA 계산
- 연봉 실수령액 계산기 - 세후 월급 계산
- 대출이자 계산기 - 원리금균등/원금균등 이자 계산
- 전세 vs 월세 비교 계산기 - 전월세 비용 비교
- 적금이자 계산기 - 적금 만기 수령액 계산

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

◆ 개발자 도구

웹 개발, 데이터 처리, 인코딩/디코딩 등 개발에 필요한 도구들입니다.

- JSON 포맷터 - JSON 정리/검증
- Base64 변환 - Base64 인코딩/디코딩
- 색상 변환기 - HEX, RGB, HSL 색상 코드 변환
- URL 인코더 - URL 인코딩/디코딩
- 정규식 테스터 - 정규표현식 실시간 테스트
- 해시 생성기 - MD5, SHA 해시값 생성
- UUID 생성기 - UUID v4 고유 식별자 생성
- HTML 엔티티 변환 - HTML 특수문자 이스케이프
- Markdown 미리보기 - 마크다운 실시간 렌더링
- 타임스탬프 변환기 - Unix 타임스탬프 ↔ 날짜 변환
- CSV ↔ JSON 변환 - 데이터 형식 상호 변환

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

◆ 생성 도구

비밀번호, 색상 팔레트, 랜덤 뽑기 등 무언가를 생성해주는 도구들입니다.

- 비밀번호 생성기 - 안전한 랜덤 비밀번호 생성
- 한글 로렘입숨 - 한국어 더미 텍스트 생성
- D-Day 계산기 - 디데이 카운터
- 색상 팔레트 생성기 - 조화로운 배색 자동 생성
- 이모지 검색기 - 이모지 한글 검색 및 복사
- 랜덤 뽑기 - 랜덤 숫자/항목 추첨
- 내 IP 주소 확인 - 공인 IP 즉시 확인
- 영문주소 변환기 - 한국 주소 영문 변환

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 이런 분들에게 추천

- 업무 중 간단한 도구가 필요한 직장인
- 개발에 필요한 유틸리티를 찾는 개발자
- 디자인 작업을 돕는 도구가 필요한 디자이너
- 계산기나 변환기를 자주 쓰는 학생

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 사용 방법

1. 사이트에 접속합니다
2. 카테고리에서 필요한 도구를 찾거나 검색합니다
3. 원하는 도구를 클릭해서 바로 사용합니다
4. 즐겨찾기에 추가해두면 다음에 더 빠르게 접속할 수 있습니다
